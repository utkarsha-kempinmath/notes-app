📝 Notes App

A simple and efficient Notes Application built using Node.js, Express.js, EJS, and MongoDB.
This app allows users to create, view, edit, and delete notes, helping them organize their thoughts and tasks in one place.

🚀 Features

➕ Create new notes

📄 View all saved notes

✏️ Edit existing notes

🗑️ Delete notes

💾 Persistent storage using MongoDB

🎨 Server-side rendering with EJS templates

🛠️ Tech Stack

Frontend: EJS (Embedded JavaScript Templates), HTML, CSS

Backend: Node.js, Express.js

Database: MongoDB (with Mongoose ODM
